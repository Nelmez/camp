Camp 1.7.2

- Brand New Native macOS App Icon:
  - Replaced legacy flat placeholder with a bespoke, Apple Human Interface Guidelines-compliant machined 3U server rack icon.
  - Matches the active `server.rack` menu bar state with illuminated emerald green online indicators, secondary activity LEDs, precision-machined ventilation grilles, and titanium quick-release latches.
  - Full macOS continuous-curvature squircle geometry with calibrated dock drop shadows and top specular rim lighting.
- Multi-Project Management:
  - Added support for creating, switching, and managing isolated web projects.
  - Per-project document roots, service feature toggles (Apache, MariaDB, FTP), and database data isolation.
  - Project switcher menu and project settings in the main window and menu bar extra.
