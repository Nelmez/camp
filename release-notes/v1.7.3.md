Camp 1.7.3

- Multi-Project Architecture & Stability Improvements:
  - Dynamic service reconciliation: automatically activates only required services (Apache, MariaDB, phpMyAdmin, ProFTPD) and safely unloads unused daemons when switching projects.
  - Isolated MySQL Data Stores: Each project with database features enabled maintains its own independent MySQL data directory, schemas, and tablespaces.
  - Template-Based Project Provisioning: Built-in support for Blank, Basic PHP, WordPress-Ready, and phpMyAdmin Test starter templates with automatic dependency enforcement.
  - Terminal CLI Suite: Manage projects from terminal with `Camp project list`, `current`, `switch`, `create`, and `delete [--trash]`.
  - Collision & Concurrency Protection: Safe slug sanitization preventing disk collisions with retained projects and robust project switch synchronization.

Install the DMG for a new installation or to bootstrap the updater. Existing Camp installations can use Check for Updates.

Unsigned preview build. macOS may show Gatekeeper warnings.
