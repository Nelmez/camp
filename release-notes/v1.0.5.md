Camp 1.0.5

- Prevent startup race condition when launching services by checking if a service is already running, and ensuring clean launchd drain and socket cleanup before re-bootstrapping.
- Completely eliminate Homebrew and non-system dylib dependencies (such as zstd in libzip) from the runtime payload so Camp runs without requiring Homebrew on other machines.
- Add compile-time and package-time validation assertions guaranteeing zero non-system dynamic library references in all shipped binaries.
- Pass explicit --defaults-file configuration to mariadb-install-db and client calls, isolating MariaDB operations from any pre-existing host /etc/my.cnf or ~/.my.cnf files.
- Configure default MariaDB UNIX domain sockets for both mysqli and pdo_mysql in php.ini, enabling out-of-the-box socket and localhost connectivity for all PHP web applications.
- Grant full administrative privileges to root on IPv6 (root@'::1') in addition to localhost and 127.0.0.1.
- Ensure the Camp Application Support root directory and its subdirectories are explicitly created with correct user ownership during package installation.

Install the DMG for a new installation or to bootstrap the updater. Existing Camp installations can use Check for Updates.
