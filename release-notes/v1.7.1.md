Camp 1.7.1

- New versioning scheme: Adopted three-tier versioning (1.X.Y) where the minor number (7) reflects major milestones and architectural stability improvements, and the patch number (1) reflects incremental features and polish.
- Live Service Resource Monitoring: Display real-time CPU % and Memory footprint (RSS) for Apache, MariaDB, and ProFTPD.
- Interactive UI & Menu Bar Extra Integration:
  - Service status rows in Web, Database, and FTP views show live CPU and memory metrics alongside running indicators.
  - Menu Bar Extra status menu displays instant per-service resource usage without opening the main window.
  - Terminal CLI (`Camp status`) reports live CPU % and Memory footprint for active services.
- Process hierarchy tracking: Automatically traverses multi-process worker pools (such as Apache httpd worker child processes) to compute accurate aggregate CPU and memory consumption.
- Comprehensive test coverage for service metric calculations and process tree aggregation.

Install the DMG for a new installation or to bootstrap the updater. Existing Camp installations can use Check for Updates.
