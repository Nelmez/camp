Camp 1.9.5

- Sparkle Auto-Updater Architecture Fix:
  - Standard Zip Distribution for Seamless In-App Updates: Switched Sparkle feed enclosures from package (.pkg) installers to application archive (.zip) updates containing Camp.app. This resolves the Sparkle 2 security restriction that aborted updates on unsigned builds where Autoupdate lacks a matching Apple Developer Team ID certificate.
  - EdDSA & Code Signing Verification: Updates are signed with EdDSA (ed25519) and application bundles are properly sealed with ad-hoc code signatures. This satisfies Sparkle's Apple Code Signing validation without requiring an Apple Developer ID certificate, preventing OSStatus -67056 validation aborts.
  - Streamlined Background Checks: Removed redundant manual background update checks in CampUpdater on initialization, delegating update check intervals directly to Sparkle's scheduler.

Install the DMG for a new installation or to bootstrap the updater. Existing Camp installations can use Check for Updates.
