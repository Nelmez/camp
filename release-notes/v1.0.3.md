Camp 1.0.3

- Fix false-timeout in MariaDB readiness check ("MariaDB did not become ready") by treating connection handshakes (including auth rejection) as readiness signals rather than waiting for full 180s timeout.
- Add self-healing root credential synchronization via automated `mariadbd --bootstrap` fallback when credentials become desynchronized or inaccessible.
- Add secure file-based fallback credential store and web config recovery to prevent Keychain lockout across unsigned/ad-hoc application updates.
- Improve error banner in Camp UI to support scrolling and text selection for long server error logs.

Install the DMG for a new installation or to bootstrap the updater. Existing Camp 1.0.1 and 1.0.2 installations can use Check for Updates.

Unsigned preview build. macOS may show Gatekeeper warnings.
