Camp 1.0.6

- Fix fatal dyld runtime failure by recompiling `libzip.5.5.dylib` without `zstd` dependency and installing it into the runtime stack, ensuring PHP and Apache run on Macs without Homebrew installed.
- Purge external-linking `mod_brotli.so` and `mod_http2.so` from Apache modules and automated build stack.
- Implement active readiness check in `ServiceController` for MariaDB using the local UNIX socket, ensuring callers and the UI wait until the database server is fully operational and accepting connections before continuing.
- Detect instant daemon crash during service startup and abort immediately with recent service log output instead of waiting for timeout.
- Clean up any stale `mysql.sock` UNIX domain socket files left behind from previous crashes or ungraceful reboots before starting MariaDB.
- Add `scripts/test-camp.sh` runner and expand automated verification suite to 42 tests covering Mach-O system isolation across all runtime binaries, configuration syntax (`httpd -t`, `proftpd -t`), foreign `~/.my.cnf` file shielding, and live PHP `mysqli` and `PDO` socket and TCP connectivity.

Install the DMG for a new installation or to bootstrap the updater. Existing Camp installations can use Check for Updates.

Unsigned preview build. macOS may show Gatekeeper warnings.
