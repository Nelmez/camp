Camp 1.0.4

- Fix MariaDB first-run initialization to connect via UNIX domain socket without credentials before TCP users are created, preventing spurious --bootstrap recovery invocations.
- Ensure MariaDB root credentials grant full administrative privileges to both 'root'@'localhost' and 'root'@'127.0.0.1'.
- Use LocalAuthentication non-blocking context for Keychain reads to prevent thread races and avoid modal authorization hangs.
- Atomically create local fallback credential file with 0600 permissions.
- Fix ProFTPD user session handling when running unprivileged by logging transfers to the Camp log directory and avoiding unprivileged chroot failures.
- Add dismiss action to the GUI error banner.

Install the DMG for a new installation or to bootstrap the updater. Existing Camp installations can use Check for Updates.

Unsigned preview build. macOS may show Gatekeeper warnings.
